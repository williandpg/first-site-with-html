<h1><strong>First Site With HTML</strong></h1>

<h2><strong>Descrição</strong></h2>
<p align="justify">
  O objetivo foi criar um site estático de uma clínica médica fictícia, aplicando todos os conhecimentos adquiridos sobre estrutura HTML, organização de páginas, tabelas, formulários, mídias e navegação entre links. 
</p>

<h2><strong>Tecnologias Utilizadas</strong></h2>
<ul>
  <li align="justify"><a href="https://developer.mozilla.org/pt-BR/docs/Web/HTML"><strong>HTML</strong></a>: Linguagem de marcação principal usada para a construção das páginas.</li>
  <li align="justify"><a href="https://code.visualstudio.com/"><strong>VS Code</strong></a>: Editor utilizado para desenvolvimento.</li>
  <li align="justify"><a href="https://developers.google.com/maps/documentation/embed/get-started?hl=pt-br"><strong>Google Maps Embed</strong></a>: Para localização da clínica.</li>
  <li align="justify"><a href="https://developer.mozilla.org/pt-BR/docs/Learn_web_development/Extensions/Forms/How_to_structure_a_web_form"><strong>Formulários HTML</strong></a>: Para entrada de dados do usuário.</li>
</ul>

<h2><strong>Estrutura do Projeto</strong></h2>
<p align="justify">A estrutura do projeto é organizada da seguinte forma:</p>

```plaintext
/
├── images/
│    ├── contato.png
│    ├── horario.png
│    ├── pagina-principal.png
│    ├── sobre.png
├── base.css
├── contato.html
├── horario.html
├── index.html
├── sobre.html
├── README.md
```

<h2><strong>Notas</strong></h2>
<ul>
  <li align="justify">Utilize imagens distintas para cada header, reforçando identidade visual por página.</li>
  <li align="justify">A tabela de horários foi criada com <strong>table, tr, th e td</strong> com foco em acessibilidade e clareza.</li>
  <li align="justify">O formulário de contato foi implementado com todos os campos solicitados, incluindo botões de envio e limpeza.</li>
  <li align="justify">O Google Maps foi embutido via <strong>iframe</strong> com coordenadas reais para simular localização.</li>
  <li align="justify">Todos os links do menu estão funcionais, permitindo a navegação entre as páginas do site.</li>
</ul>
